# Hair Salon Appointment System

A full-stack web application developed as an Engineering Design Project at Selçuk University.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **API:** RESTful APIs

## Features
- User registration and login
- Customer, salon owner, and admin dashboards
- Hair salon listings and location filtering
- Online appointment booking and management
- Service management
- Customer reviews and ratings
- AI-powered salon assistant
- Contact form and message management

## Project Description
This project aims to simplify appointment scheduling for hair salons by providing a centralized platform where customers can browse salons, book appointments, and track reservations.

Salon owners can manage their services and appointments, while administrators can monitor platform activity.
